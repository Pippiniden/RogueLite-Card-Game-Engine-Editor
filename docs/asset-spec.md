# アセット規格（画像・UIスキン・音）

RogueLite Card Game Engine & Editor で使う素材の規格です。
**この規格どおりに作れば、どの端末でもにじまず・はみ出さず・差し替えるだけで動きます。**
規格から外れても動きます（拡大縮小されるだけ）。エディターの「素材」画面は、規格と違うサイズを黄色で知らせます。

---

## 1. 共通ルール

| 項目 | 規格 | 理由 |
| --- | --- | --- |
| 基準解像度 | 画面は **390×844（CSS px）** の縦持ち。ラスター画像は **@2x（2倍）** で作る | 現行スマホの大半は 2〜3 倍密度。@2x なら3倍密度でもほぼ劣化が見えず、容量は @3x の約半分 |
| 色空間 | **sRGB・8bit/チャンネル** | ブラウザの既定。P3 や 16bit は端末で色が変わる・重い |
| 透過 | **ストレートアルファ**（乗算済みにしない）。縁に 1〜2px の余白 | 縮小時に黒いフチが出ない |
| 形式（絵） | **WebP（品質 80〜90）** を推奨、PNG も可 | WebP は PNG の 1/3〜1/5。全モダンブラウザ対応 |
| 形式（UI枠・アイコン） | **PNG-32** または **WebP ロスレス**。単純な図形なら **SVG** も可 | 9スライスの縁が劣化しない |
| SVG | 外部ファイル・フォント・スクリプトを参照しない**自己完結**のもの。`viewBox` と `width`/`height` を書く | 単体で表示でき、サイズ判定もできる |
| 使わない形式 | JPEG の透過（不可能）・GIF・BMP・TIFF・HEIC | 対応外か重い |
| 1枚の上限 | 背景 600KB、その他 200KB を目安 | スマホ回線での初回読み込み |
| ファイル名 | 小文字英数字と `_` だけ。例 `assets/enemy/ash_dragon.webp` | 大文字小文字を区別するサーバ（GitHub Pages）で事故が起きない |

### 論理キー

画像はコードやデータから**ファイル名ではなく論理キー**で呼びます。対応表は各パックの `assets/manifest.json`。

```json
{ "enemy.ash_dragon": "enemy/ash_dragon.webp", "ui.dialog": "ui/dialog.png" }
```

- キーは `分類.名前[.細分]`（小文字）。分類は下の表の見出し（`portrait` `enemy` `card` …）。
- ファイルは `assets/<分類>/` に置く。
- 後に読むパックが同じキーを書けば、そのパックの画像に差し替わります（元のパックは触らない）。
- キーに画像が無いときは仮の絵（自動生成）か CSS で描かれます。**画像が無くてもゲームは止まりません。**

## 2. 絵の規格

| 分類（キーの頭） | 用途 | サイズ（@2x） | 形 | 備考 |
| --- | --- | --- | --- | --- |
| `portrait.<キャラ>.<表情>` | 主人公の顔 | **512×512** | 正方形・透過可 | 表情は `normal`（通常）`hurt`（被弾）`pinch`（HP30%以下）`happy`（勝利・回復）。`normal` 以外は省略可（normal で代用）。どのキーを使うかは `characters.json → portrait`。顔は中央 70% に。円形・角丸どちらで切り抜かれても欠けないように |
| `characters.json → selectArt` に書いたキー | 主人公選択の大きな絵 | **768×768** | 正方形 | 円形に切り抜かれる。重要な部分は中央の円（直径 90%）の中に |
| `enemy.<敵>` | 敵 | 高さ **small 256 / medium 384 / large 448 / boss 576**。幅は高さの 1.25 倍まで | 透過 | **足元を下端中央**に置く。影は絵に含めない（エンジンが付ける）。足元より下に余白がある絵は `footOffset`（高さに対する割合）で補正 |
| `card.<カード>` | カードの絵 | **640×360（16:9）** | 長方形 | 主題は中央 80% に。カード枠の都合で上下左右 5% ずつ切れることがある |
| `status.<状態>` | 状態アイコン | **128×128** | 透過 | 絵は中央 112×112 に。**24px 表示でも読める**太い形。数字は入れない（スタック数はエンジンが重ねる） |
| `relic.<レリック>` | レリック | **128×128** | 透過 | 同上 |
| `intent.<種類>` | 敵の行動予告 | **128×128** | 透過 | `attack` `defend` `buff` `debuff` `unknown` |
| `node.<種類>` | マップのノード | **128×128** | 透過 | `battle` `elite` `rest` `treasure` `boss` |
| `scene.<名前>` | 焚き火などの場面の絵 | **400×400** | 透過 | |
| `bg.<名前>` | 画面の背景 | **780×1688** | 不透明 | 下記「背景のセーフゾーン」参照。JPEG（品質 80）も可 |

### 背景のセーフゾーン

```
┌──────────────── 780 ────────────────┐
│  上 94px：時計・ノッチに隠れる        │ ← 絵柄の大事な部分を置かない
├──────────────────────────────────────┤
│                                      │
│        ここが確実に見える範囲          │
│                                      │
├──────────────────────────────────────┤
│  下 68px：ホームバーに隠れる          │
└──────────────────────────────────────┘ 1688
```

- 縦横比が違う端末では `cover` で拡大されるため、**左右それぞれ 10%** は切れても困らない絵にする。
- 戦闘画面の背景は、上 1/2（敵が立つ場所）が暗めだと敵とHPバーが見やすい。
- 背景を指定するのは `theme.json → backgrounds`（画面ID → キー）か、遭遇ごとの `encounters.json → bg`。

## 3. UIスキン（窓枠・ボタンなど）

### 仕組み

UI の部品はどれも **CSS だけで描いた見た目を内蔵**しています。
`theme.json → skins` に部品名と画像を書くと、その部品だけが**9スライス画像**に置き換わります（CSS `border-image`）。
画像が見つからないときは CSS の見た目に戻ります。

```json
"skins": {
  "dialog": { "image": "ui.dialog", "slice": [32, 32, 32, 32], "scale": 2, "fill": true },
  "button.primary": { "image": "ui.button.primary", "slice": [24, 24, 24, 24], "scale": 2,
                      "css": { "color": "#fff4e2" } }
}
```

| 項目 | 意味 |
| --- | --- |
| `image` | 画像の論理キー（`ui.〜` を推奨） |
| `slice` | 上・右・下・左の切り取り幅（**元画像の px**） |
| `scale` | 元画像の何 px を画面の 1px にするか。**@2x で描いたら 2**（既定） |
| `fill` | 中央部分も描くか（既定 true）。false なら中央は透明で、部品の背景色が見える |
| `repeat` | 辺の伸ばし方。`stretch`（既定）`round` `repeat` `space` |
| `css` | その部品に足す CSS（文字色・余白など） |

### 9スライスの描き方

```
 slice[3]=左          slice[1]=右
   ┌──┬────────────┬──┐
   │角│  上の辺     │角│ slice[0]=上
   ├──┼────────────┼──┤
   │左│            │右│
   │辺│   中央      │辺│   ← 伸びる
   ├──┼────────────┼──┤
   │角│  下の辺     │角│ slice[2]=下
   └──┴────────────┴──┘
```

- **装飾は四隅に**。辺は伸びるので、単色・グラデーション・縦横どちらかにだけ繰り返す模様にする。
- 中央は伸びるので、ベタ塗りか薄い質感だけにする。
- 推奨サイズ（@2x）: 窓 **96×96（slice 32）**、ボタン **96×64（slice 24）**。それより大きくてもよい。
- 角の大きさ（slice）は、表示上の最小の部品の高さの半分以下に（ボタンは表示高さ 44px → @2x で 88 → slice 44 以下）。
- 透過の外周（影など）を描く場合はその分 slice を大きく取る。

### 部品名

| 部品名 | 場所 | 推奨サイズ（@2x）/ slice |
| --- | --- | --- |
| `button` | 普通のボタン | 96×64 / 24 |
| `button.primary` | 主ボタン（ターン終了・出発など） | 96×64 / 24 |
| `button.disabled` | 押せないボタン（`button` と `button.primary` の両方に効く） | 96×64 / 24（slice は `button` と同じにする） |
| `dialog` | ダイアログ・情報の窓 | 96×96 / 32 |
| `panel` | 画面内の囲み | 96×96 / 24 |
| `topbar` | 上部バー | 64×48 / 下だけ 8（`[0,0,8,0]`） |
| `banner` | 「敵のターン」などの帯 | 128×64 / 左右 40 |
| `reward.item` | 報酬の1行 | 96×64 / 24 |
| `map.node` / `map.node.boss` | マップのノードの台座 | 128×128 / 40 |
| `gauge.track` / `gauge.fill` | HPバーの溝と中身 | 64×24 / 左右 10 |
| `energy` | エネルギーの玉 | 128×128 / 0（`fill` で全体を描く） |
| `card.frame.<種類>` | カードの枠（`attack` `skill` `power` `status` `curse`） | **192×268**（比率 96:134）/ 28 |
| `card.cost` | カードのコストの玉 | 64×64 / 0 |
| `card.panel` | カードの説明文の台紙 | 96×96 / 16 |

部品名の一覧はエディターの「見た目・UIスキン」と `src/game/registry-names.ts → SKIN_PARTS` にあります。
画面配置で `skin="部品名"` を付けると、どの要素にもスキンを当てられます。

見本: `public/packs/skin-demo/`（`node tools/gen-skin-demo.mjs` で作り直せる）。
ゲームの URL に `?packs=base,skin-demo` を付けると試せます。常に使うなら `public/packs/index.json` に足します。

## 4. 音

| 種類 | 形式 | 長さ・音量 | 備考 |
| --- | --- | --- | --- |
| 効果音（SE） | **AAC（.m4a）** または **MP3**、44.1/48kHz、モノラル可 | **2秒以内**、ピーク **−1 dBTP** | 頭の無音は 10ms 以下（遅れて聞こえる） |
| 音楽（BGM） | **AAC（.m4a, 128〜160kbps）** または **MP3** | ラウドネス **約 −18 LUFS**（効果音より控えめ） | ループは `audio.json → tracks.<キー>.loopStart / loopEnd`（秒） |

- Ogg/Opus は iOS の古い版で鳴らないことがあるため使わない。WAV は重いので避ける。
- 鳴らす場面は `audio.json`：`se`（場面名 → キー。`click` `cardPlay` `hit` `block` `buff` `debuff` `victory` `defeat` など）と `bgm`（画面ID か `battle` `elite` `boss` → キー）。
- 音量の調整は `audio.json → tracks.<キー>.volume`（0〜1）と `volume.master / se / bgm`。
- スマホは最初の操作まで音を出せません。エンジンは最初のタップで自動的に鳴らし始めます。

## 5. チェックリスト

- [ ] @2x のサイズで作った（UI枠・アイコンは PNG/WebP ロスレス、絵は WebP）
- [ ] sRGB・ストレートアルファ・縁に余白
- [ ] 敵は足元が下端中央、影なし
- [ ] アイコンは 24px に縮めても読める
- [ ] 背景の上 94px・下 68px・左右 10% に大事なものがない
- [ ] 9スライスの装飾は四隅だけ、`scale: 2`
- [ ] ファイル名は小文字英数字と `_`、`manifest.json` に論理キーで登録した
- [ ] `npm run check` で「画像がありません」が出ない
